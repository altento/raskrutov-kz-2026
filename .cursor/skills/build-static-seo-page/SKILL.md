# Создание статической SEO-страницы

1. Прочитать `PROJECT_PROFILE.md`, `AGENTS.md` и применимые `.cursor/rules/*.mdc`.
2. Проверить git status, структуру, общие компоненты и эталон страницы того же типа.
3. Зафиксировать задачу страницы: интент, URL, H1, CTA, материалы и внутренние ссылки. Неизвестное отметить `ТРЕБУЕТ ПОДТВЕРЖДЕНИЯ`.
4. Реализовать mobile-first на текущем стеке. Сохранить общий header/footer, формы, аналитику и дизайн-систему.
5. Определить вероятный LCP. Сделать первый экран независимым от JavaScript и подключить адаптивный LCP-ресурс из HTML.
6. Проверить title, description, canonical, заголовки, alt, хлебные крошки и JSON-LD по видимому содержимому.
7. Запустить `npm run quality:all`. Исправить ошибки, относящиеся к задаче.
8. Проверить 360, 390, 412, 430 и 1280 px, меню, CTA, формы, модальные окна и консоль.
9. При доступном Chrome запустить `npm run lighthouse:mobile -- <URL>`, использовать медиану трёх прогонов.
10. Показать список файлов, результаты проверок, риски и git diff. Остановиться без commit, push и публикации.
