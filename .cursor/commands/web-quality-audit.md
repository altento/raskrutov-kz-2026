# Web Quality Audit

Используй навык проекта `.agents/skills/web-quality-audit/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Проведи комплексный аудит качества текущей страницы или сайта.
3. Проверь HTML, CSS, JavaScript, адаптивность, доступность, SEO, производительность, формы и ссылки.
4. Не вноси несвязанные изменения.
5. В конце раздели результаты на критичные ошибки, улучшения и успешно пройденные проверки.
