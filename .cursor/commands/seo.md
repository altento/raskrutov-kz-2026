# SEO

Используй навык проекта `.agents/skills/seo/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Выполни текущую SEO-задачу строго по инструкции навыка.
3. Сверяй URL, Title, Description, H1, canonical, индексируемость и внутренние ссылки с актуальной SEO-картой.
4. Не меняй опубликованные URL без явного решения в карте.
5. В конце перечисли изменения и проверки.
