# SEO Audit

Используй навык проекта `.agents/skills/seo-audit/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Проведи SEO-аудит текущей страницы или проекта по инструкции навыка.
3. Проверь техническое SEO, метаданные, canonical, индексацию, контент, перелинковку, изображения и Schema.org.
4. Раздели проблемы по критичности и не исправляй несвязанные файлы без необходимости.
5. В конце дай перечень найденных ошибок и выполненных исправлений.
