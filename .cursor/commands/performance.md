# Performance

Используй навык проекта `.agents/skills/performance/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Оптимизируй текущую страницу или проект строго по инструкции навыка.
3. Не ломай порядок загрузки `public.bundle`, формы, метрику и интерактивность.
4. Проверяй LCP, CLS, INP, вес изображений, шрифты, CSS и JavaScript.
5. В конце перечисли изменения и ожидаемый эффект.
