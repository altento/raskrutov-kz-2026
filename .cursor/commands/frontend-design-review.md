# Frontend Design Review

Используй навык проекта `.agents/skills/frontend-design-review/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Проведи ревью текущей страницы или интерфейса по инструкциям навыка.
3. Учитывай адаптивность, иерархию, читаемость, контраст, состояния элементов и визуальные дефекты.
4. Не меняй бизнес-логику без необходимости.
5. В конце перечисли критичные и некритичные замечания.
