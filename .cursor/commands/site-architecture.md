# Site Architecture

Используй навык проекта `.agents/skills/site-architecture/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Выполни задачу по архитектуре сайта строго по инструкции навыка.
3. Сверяй структуру с `site-map.csv`, `url-map.tsv`, существующими страницами и внутренней перелинковкой.
4. Не создавай дублирующие разделы и не меняй действующие URL без основания.
5. В конце перечисли изменения структуры, родительские связи и риски.
