# Webapp Testing

Используй навык проекта `.agents/skills/webapp-testing/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Протестируй текущую страницу или веб-приложение строго по инструкции навыка.
3. Проверь основные пользовательские сценарии, формы, кнопки, навигацию, адаптивность и ошибки консоли.
4. Не меняй рабочую бизнес-логику без необходимости.
5. В конце перечисли тестовые сценарии, найденные дефекты и исправления.
