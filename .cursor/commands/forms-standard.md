# Forms Standard

Используй навык проекта `.agents/skills/forms-standard/SKILL.md`.

1. Найди и полностью прочитай указанный `SKILL.md`.
2. Выполни текущую задачу пользователя строго по инструкциям навыка.
3. Учитывай правила проекта из `.cursor/rules/`.
4. Особое внимание удели корректным `name`, `id`, `label`, типам полей, валидации и доступности.
5. Не меняй интеграции и обработчики форм без необходимости.
