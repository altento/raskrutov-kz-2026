# Источники и лицензии

Дата сборки: 4 августа 2026 года.

Этот пакет **не является зеркальной копией** исходных репозиториев. Инструкции заново структурированы и адаптированы для проектов веб-студии на чистом HTML/CSS/JS. Названия и функциональные направления вдохновлены следующими открытыми проектами.

## 1. Addy Osmani — Web Quality Skills

Источник: `addyosmani/web-quality-skills`

Использованные направления:

- web-quality-audit;
- performance;
- core-web-vitals;
- accessibility;
- seo.

Лицензия исходного репозитория: MIT.

## 2. Corey Haines — Marketing Skills

## 3. Anthropic — Agent Skills

Источник: `anthropics/skills`, навык `webapp-testing`.

Использован общий процесс браузерного тестирования. В пакет не включены оригинальные скрипты и зависимости.

Многие открытые навыки репозитория распространяются по Apache License 2.0; конкретные условия указываются в `LICENSE.txt` соответствующего навыка.

## 4. Microsoft — Skills

Источник: `microsoft/skills`, навык `frontend-design-review`.

Использованы направления визуального, responsive и UX-ревью. Специфичные требования к Azure, Storybook и Figma не переносились.

Лицензия исходного репозитория: MIT.

## Политика обновления

Перед переносом новых версий из открытых репозиториев:

1. просмотреть изменения;
2. проверить новые scripts и зависимости;
3. убедиться, что нет чтения `.env`, ключей и внешней отправки данных;
4. протестировать в отдельной ветке;
5. обновить дату и версию навыка.
