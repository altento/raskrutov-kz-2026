# Профиль проекта raskrutov.kz

- Проект: сайт веб-студии «Раскрутов».
- Домен: https://raskrutov.kz
- Стек: чистые HTML, CSS и JavaScript.
- Приоритет: мобильная версия, SEO/AEO, доступность, высокая реальная производительность.
- Целевые страницы: главная, хабы, услуги, региональные страницы, кейсы, информационные страницы.
- Аналитика: сохранять действующий ID Яндекс Метрики, цели и события; исключать дублирование.
- Формы: сохранять интеграции; обязательны label, name, type, required где поле обязательно, autocomplete, согласие и источник страницы.
- SEO: один H1, уникальные title/description, canonical, хлебные крошки, корректная перелинковка и JSON-LD только по видимым подтверждённым данным.
- Тексты: уверенные прямые формулировки. Не использовать риторические противопоставления и шаблоны «не X, а Y», «это не просто X».
- Безопасность работ: не менять URL, аналитику, формы, контакты и опубликованный контент без требования задачи.
- Выпуск: commit, push и публикация только по отдельной команде пользователя.

## Целевые показатели мобильного Lighthouse

- Performance: медиана трёх запусков от 90.
- LCP: до 2,5 с.
- CLS: до 0,1.
- TBT: до 200 мс.
- Accessibility: от 95.
- SEO: 100.
