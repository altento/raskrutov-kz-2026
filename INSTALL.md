# Установка в raskrutov-kz-2026

1. Сделайте резервную копию или отдельную ветку.
2. Скопируйте **содержимое** этой папки в корень репозитория сайта. Скрытая папка `.cursor` тоже должна скопироваться.
3. Если в проекте уже есть одноимённые файлы, не заменяйте их вслепую: объедините правила и scripts из `package.json`.
4. В терминале Cursor, открытом в корне проекта, выполните:

```powershell
npm install
npm run quality:all
```

5. Для локальной проверки опубликованной или запущенной страницы:

```powershell
npm run lighthouse:mobile -- https://raskrutov.kz/web-studiya/sozdanie-saitov/
```

Пакет не делает commit, push и публикацию. Ошибки аудита нужно исправить до масштабирования страницы.

## Как использовать в Cursor

Обычная команда:

> Создай/измени страницу по правилам репозитория. Применяй навык `.cursor/skills/build-static-seo-page/SKILL.md`. После работы запусти `npm run quality:all`, покажи результаты и git diff. Commit, push и публикацию не выполняй.

## Файлы проекта

- `PROJECT_PROFILE.md` уже заполнен под raskrutov.kz.
- `site-standard.config.json` использует автоматический поиск HTML и стандартную папку `assets`.
- Если фактическая структура отличается, Cursor сначала должен показать найденные пути и предложить точечную правку конфигурации.
